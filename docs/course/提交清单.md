## 本分支里没有的

| 材料 | 原因 |
| --- | --- |
| 视频文件 | 没有录 GUI。`docs/course/讲解稿.md` 只是口播稿 |
| 完整小组 ZIP | 课程要求的 ZIP 要同时包含代码、报告和 5 分钟以内的视频。视频文件还没有，所以没有把一个不完整的包再压进仓库 |
| 可单独双击运行的 exe 环境 | `received/d/车牌识别系统.exe` 只是约 4.6 KB 的启动器。`runtime/` 未入库 |
| 第二台 Windows 电脑的 exe 测试 | `received/d/docs/另一台电脑测试记录.md` 的第二台复测表是空的。本分支不填写、也不声称已测 |
| 用 A 的 `detect_plates` 重跑的课程表 | 冻结的那一次运行没有加载 `vendor/a_plate` |

## 若以后要打成一个小组 ZIP

建议包含：

1. 本仓库中的 `received/`、`data/`、`eval/`、`docs/course/`。
2. 提交仓库里的 `pipeline.py`、`app/` 和 `vendor/`，或该仓库的发布页链接与提交号 `d7e9d13c6ed0361f9b7cebeefa9d0eb59d3c7ec3`。
3. 按讲稿补拍的视频，时长不超过 5 分钟。演示图用 `data/raw/development/`。
4. 若小组决定附上可运行程序，使用发布页上含 `runtime/` 的原压缩包，并在第二台电脑复测之后再把记录写进 D 的那份空表。

不要放进 ZIP 的内容：`eval/fixtures/` 的夹具分数当作识别率、提交仓库 `samples/` 的 8 张合成图当作终测、私人车牌照片。
