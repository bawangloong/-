## 二、PyInstaller 打包（课程推荐方式）

### 1. 安装

```bash
pip install pyinstaller
```

### 2. 打包

```bash
pyinstaller build/plate_app.spec --noconfirm --clean
```

生成 `dist/车牌识别系统/`，双击其中的 `车牌识别系统.exe` 即可。

### 3. spec 说明

`build/plate_app.spec` 做了四件事：

1. 入口为项目根目录的 `main.py`；
2. `pathex` 指向项目根目录，保证 `app`、`vendor` 能被分析到；
3. 把 `vendor/c_char/character_library/`（`library.npz` + `library.json`）作为
   data 复制到发行目录，运行时由 `app/runtime.py` 用 `sys._MEIPASS` 定位；
4. 声明 `PIL._tkinter_finder` 隐藏导入，避免 Pillow 与 Tk 一起打包时缺少模块。

`console=False` 生成窗口程序；启动异常由 `app_main.py` 写
`logs/startup_error.log` 并弹窗。

### 4. 打包后检查

- `dist/车牌识别系统/_internal/vendor/c_char/character_library/library.npz` 存在；
- 双击 exe，能选图、识别、保存；
- 断开网络后仍能运行；
- 在未安装 Python 的电脑上复测（见 `docs/另一台电脑测试记录.md`）。

## 三、绿色免安装包（本次实际交付）

本机无法访问 PyPI（TLS 被网络策略拦截、HTTP 返回 403），无法安装
PyInstaller，因此额外提供“自带 Python 运行时”的绿色方案：

```powershell
powershell -ExecutionPolicy Bypass -File build/make_portable.ps1
```

脚本内容：

1. 复制 Python 3.13 的 `pythonw.exe`、DLL、`DLLs/`、`Lib/`（去掉 `test` 等
   非必要目录）、`tcl/`；
2. 复制 `numpy`、`cv2`、`PIL` 及其 dist-info 到 `runtime/Lib/site-packages`；
3. 去掉 `opencv_videoio_ffmpeg500_64.dll`（约 30 MB，图片识别不需要）；
4. 复制 `app/ vendor/ samples/ docs/` 和入口 `app_main.py`；
5. 用 .NET `csc.exe` 编译 `build/Launcher.cs` 为 `车牌识别系统.exe`。

启动器逻辑：以 exe 所在目录为工作目录，调用
`runtime\pythonw.exe app_main.py`；缺文件时弹窗提示“发行包不完整”。

优点：目标电脑不需要 Python、不需要联网、与开发环境完全一致；
缺点：体积约 211 MB（压缩后约 82 MB）。

## 四、资源与路径约定

| 资源 | 源码位置 | 打包后位置 |
|---|---|---|
| 字符库 | `vendor/c_char/character_library/library.npz` | `_internal/vendor/...`（PyInstaller）或 `vendor/...`（绿色包） |
| 日志 | `logs/plate_app.log` | exe 同级 `logs/` |
| 导出结果 | `results/`（默认） | exe 同级 `results/` |
| 演示图 | `samples/` | exe 同级 `samples/` |

`app/runtime.py` 的 `bundle_root()` 处理 `sys._MEIPASS`；`writable_root()`
固定在 exe 目录，避免写入临时解包目录。

## 五、常见打包问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 启动报 `library_missing` | spec 没带 `character_library` | 检查 datas 和 `_internal/vendor` |
| `No module named vendor...` | `pathex` 未包含项目根 | spec 中 `pathex=[str(ROOT)]` |
| 中文路径读图失败 | 用了 `cv2.imread` | 本项目统一用 Pillow 解码，勿改回 |
| 界面字体发虚 | 未声明 DPI | `enable_dpi_awareness()` 已在启动时调用 |
| exe 被杀毒软件拦截 | 未签名 | 添加信任或使用绿色包 |
| 绿色包双击没反应 | 未完整解压，`runtime/` 丢失 | 重新解压整个目录，查看 `logs/startup_error.log` |
