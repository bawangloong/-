# B 模块报告正文（车牌颜色识别与字符分割）

> 可直接并入大作业报告。括号内为需要按真实数据补填的数字。

## 1 模块目标与位置

本模块处在识别流水线的第二环：接收 A 输出的**单块车牌彩色图**，完成两件事——

1. 判断车牌**颜色类别**（蓝 / 黄 / 绿 / 白 / 黑）；
2. 把车牌**切成按阅读顺序排列的字符图片**，并给出字符个数与分割状态。

输出交给 C 做字符匹配，交给 D 在界面上展示分割过程。

## 2 方法

### 2.1 颜色识别

车牌底色是强特征，因此不做分类器，直接用颜色统计：

1. 去掉四周 10% 边缘（避免边框、铆钉干扰）；
2. RGB 转 HSV，统计**饱和且不太暗**（S>60、V>60）的像素；
3. 把这些像素按色相归入三段：蓝 190–260°、黄 20–65°、绿 65–190°；
4. 某段占比超过 45% 即判为该色，否则判 `unknown`；
5. 饱和像素不足 30% 时，说明是**无彩色**车牌，再按亮度中位数分白牌（V>150）与黑牌（V<80）。

同时输出置信度（占比）与统计明细，便于诊断误判。

### 2.2 字符分割

流程共七步：

| 步骤 | 做法 | 目的 |
|---|---|---|
| 1 归一化 | 按高度缩放到 140 px，保持长宽比 | 统一后续所有阈值 |
| 2 二值化 | 灰度 + Otsu，按前景像素占比自动定极性 | 同时兼容"蓝底白字"与"黄底黑字" |
| 3 补断笔 | 3×3 闭运算 | 字符笔画断裂会导致过切 |
| 4 去干扰 | 连通域分析，去掉贴边块、小面积噪点、上下边缘的矮块 | 去边框、铆钉、污点 |
| 5 投影切分 | 垂直投影取列区间 | 切出候选字符列 |
| 6 修补 | 合并间隙 ≤2 px 的碎块；宽度 >1.45 倍标准宽的块按投影最小值拆开 | 处理断笔与字符粘连 |
| 7 过滤与归一化 | 按高度去掉中间小圆点，按宽度去掉噪点，统一缩放到 40×20 | 输出给 C |

**为什么要自动定极性**：蓝牌是白字、黄牌是黑字，若固定阈值方向，另一类车牌会整块反转。
这里用"前景像素占比应落在 3%–45%"作为判据，两种极性里取合理的那一个，对常见车牌都成立。

**为什么要单独处理小圆点**：中国车牌第 2、3 位之间有一个分隔圆点（`·`）。
它在投影上是一个独立的小列块，若不处理会被当成一个字符，导致"+1 位"的计数错误。
本模块用**高度判据**剔除：圆点高度约为字符的 1/3，低于车高的 32% 即丢弃。

### 2.3 7 位与 8 位车牌

- 普通车牌：省份汉字 + 字母 + 5 位字母数字 = **7 位**；
- 新能源车牌：省份汉字 + 字母 + 6 位 = **8 位**。

本模块不做位数分类，只输出**实际切出的字符数**；7 或 8 记为 `ok`，
其余记为 `count_abnormal` 并保留切分结果——因为位数判断依赖字符识别结果（如新能源第 3 位为 D/F），
属于 C 与上层逻辑的职责。

## 3 接口约定

| 数据 | 格式 |
|---|---|
| 输入 | RGB 彩色图（`numpy.uint8`，H×W×3）或图片路径 |
| 字符图 | `numpy.uint8`，**40 高 × 20 宽**，白色=笔画、黑色=背景 |
| 顺序 | 从左到右，不含分隔圆点 |
| 状态 | `ok` / `count_abnormal` / `no_char` |

与 C 约定：字符图尺寸、前景背景、排序方式三项固定，C 不需要再做归一化。

## 5 失败案例分析

**案例：blue_tilt.png（倾斜 6°）**

- 现象：切出 5 个字符，状态 `count_abnormal`
- 原因：垂直投影假设字符列是竖直的。车牌倾斜后，同一列在多行上错位，
  投影谷被填平，相邻字符连成一块；同时倾斜使整体变矮，触发了宽度过滤
- 结论：**倾斜必须在 A 的矫正环节解决**，B 不做几何校正
- 处理：本模块如实返回 `count_abnormal` 并保留切片，供上层决定是否拒识或重试

**另一类可预期的问题**

- 字符粘连（如 `1` 与 `1` 之间的间隔小于阈值）→ 被切成一块，拆分后位置可能偏移半个字宽
- 强反光导致局部过曝 → 二值化后笔画断裂，闭运算核偏小会过切
- 泥污遮挡某个字符 → 该字符高度不足被过滤，字符数偏少

## 6 局限与改进方向

1. **不做几何校正**：倾斜、透视变形依赖 A 的矫正输出。
2. **阈值是经验值**：`0.32×车高` 的高度判据、`1.45×标准宽` 的拆分判据来自合成数据，
   在真实数据上需要用一批样本重新标定（建议 A 提供 50 张真实车牌做调参集）。
3. **未处理渐变底色**：新能源绿牌有渐变，若二值化不稳，可改用局部自适应阈值（Sauvola）。
4. **未使用深度学习**：按作业要求采用传统方法，优点是无需训练、可解释、打包小；
   缺点是复杂光照与低分辨率下不如端到端方案。
